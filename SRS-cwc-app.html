Overview

Purpose: cwc-app is a Laravel-based dashboard for CCTV/IOT monitoring (camera health, alerts, CO2/PH3, sack-counting, FRS).

Functional Requirements (summary)

  • Dashboard: aggregated stats
  • Camera network: region → warehouses, warehouse details
  • Alerts: CO2/PH3 + fire/smoke/rodent reporting
  • Sack counting: region summary & logs
  • FRS: unknown-person counts
  • CRUD: Regions, Warehouses, Users (RBAC)
  • Theme toggle, profile management
  • Caching and manual refresh endpoint

API Reference (high level)

  • GET /api/dashboard/stats — returns aggregated stats (supports region, warehouse, days)
  • POST /api/dashboard/refresh — force refresh
  • GET /api/warehouses?region= — returns warehouses by region
  • GET /cameras/region/{region}/warehouses — AJAX warehouses list
  • GET /cameras/{region}/{warehouse}/details — warehouse details view
  • GET /api/sack/region-summary — sack region summary (cached)
  • IoT dropdowns: /iot/sack/regions, /iot/sack/warehouses, /iot/frs/regions, /iot/frs/warehouses

Acceptance Criteria (selected)

Dashboard — View Aggregated Stats

  • GIVEN: authenticated user with permission:view_dashboard
    • WHEN: GET /api/dashboard/stats
    • THEN: respond 200 with success:true and data (camera totals, alerts, co2/ph3, sack, frs, regionData, mapData).
  • Filtering by region/warehouse recalculates totals and mapData.
  • On exception return 500 with success:false and a message.

Region → Warehouses (AJAX)

GIVEN authenticated user, GET /cameras/region/{region}/warehouses returns JSON with warehouses array and count; items filtered by region case-insensitively.

Sack Region Summary

GET /api/sack/region-summary returns deduplicated region totals cached for 300s; on failure returns success:false and empty data.
